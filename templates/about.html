How it works

NLP-based recruitment in seven steps

  1. Register: Candidates create an account with validated credentials.
  2. Upload: Upload resumes as PDF, DOCX, or TXT files, or paste text directly.
  3. NLP parsing: The system extracts text, tokenizes content, and identifies skills using NLP.
  4. TF-IDF matching: Resumes are vectorized and scored against job descriptions using cosine similarity.
  5. Rank: Applications are ranked by match score so the best candidates surface first.
  6. Review: Admins review candidates with skill breakdowns and analytics dashboards.
  7. Decision: Mark candidates as selected or rejected with full audit trail.

Use cases

Candidate

  • Upload resumes (PDF, DOCX, TXT)
  • Get automatic skill extraction
  • Browse and apply to jobs
  • See NLP match scores
  • Track application status

Admin

  • Post jobs with detailed descriptions
  • View NLP-ranked applicants
  • Review extracted skills per resume
  • Generate analytics reports
  • Track pipeline health

NLP techniques used

  • Text extraction — PDF and DOCX parsing with pdfplumber and python-docx
  • Tokenization — Breaking text into normalized word tokens
  • Skill extraction — Pattern matching against a curated skill taxonomy
  • TF-IDF vectorization — Converting text to weighted feature vectors
  • Cosine similarity — Measuring semantic closeness between resume and job description
